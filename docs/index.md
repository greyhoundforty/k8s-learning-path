# Kubernetes on IBM Cloud: Comprehensive Learning Path

Welcome to the comprehensive guide for learning Kubernetes on IBM Cloud. This guide is structured as a series of sessions, each building on the previous one to develop a solid understanding of Kubernetes principles and practices using IBM Cloud Kubernetes Service.

## Learning Path Overview

1. **Background and Getting Started**
2. **Architecture and Components**
3. **Core Resources**
4. **Application Management**
5. **Configuration Management**
6. **Networking**
7. **Storage**
8. **Security**
9. **Observability**
10. **Advanced Topics and Production Readiness**

Each session includes conceptual information followed by hands-on labs to reinforce learning.

## Prerequisites

- IBM Cloud account
- Basic knowledge of containerization concepts
- Familiarity with command-line interfaces

## How to Use This Guide

The guide is designed to be followed sequentially, but you can also jump to specific topics based on your needs. Each session includes:

- Conceptual explanations
- Diagrams and illustrations
- Hands-on examples with IBM Cloud
- Lab exercises

Let's get started with [Session 1: Background and Getting Started](session1-background/index.md)!
